# Dialoguer avec GitHub Copilot sur son abonnement

## Description

Ajouter GitHub Copilot comme troisième fournisseur de conversation BMad, sur le modèle du connecteur Claude Code (epic 6). Le porteur s'authentifie avec l'outil officiel ; Madness n'administre ni secret ni facturation. Copilot s'active dans la « dynamic island » du fournisseur livrée en 6.2, où il apparaît d'ici là grisé, avec « bientôt ».

## Outcome

Depuis un projet BMad existant, le porteur choisit GitHub Copilot dans la dynamic island, envoie un message et retrouve la réponse sous le fournisseur et le projet d'origine.

## Notes

- Décision : 2026-11-07. Le porteur valide l'idée de dynamic island et l'ouverture d'un epic séparé pour Copilot.
- À raffiner : voie officielle utilisable (CLI ou agent Copilot), modalités de connexion personnelle, capacités et limites, logo et droits d'usage.
