# Ouvrir la maquette Madness

Ouvrir `prototype/index.html` dans un navigateur, par exemple par double-clic depuis l'Explorateur Windows. Conserver les fichiers voisins dans le même dossier. La maquette ne dépend pas du serveur de choix Impeccable ; ses fichiers sont enregistrés dans ce dépôt.

L'aperçu local ouvert par Codex pendant la séance sert les mêmes fichiers. Si cet aperçu n'est plus disponible, l'ouverture directe du fichier HTML reste possible.

Les projets, dialogues, installations, approbations et changements de fichiers présentés sont des simulations. Aucun compte Codex, dossier externe ou abonnement n'est utilisé. L'action d'ouverture dans l'éditeur est présentée comme une intégration à construire.

Pour la prise en main : retrouver Madness et son attente, comprendre l'état du brief et ouvrir son aperçu, puis lancer le travail UX et poursuivre la conversation. Le catalogue permet aussi d'explorer les autres possibilités BMad installées. La commande de réinitialisation restaure le scénario de départ.

Cette maquette sert à recueillir du feedback sur les trois parcours. Elle ne choisit pas encore le framework UI ni le packaging Electron ou navigateur avec moteur local.
